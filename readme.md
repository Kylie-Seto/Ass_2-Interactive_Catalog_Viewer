# Ass_2-Interactive_Catalog_Viewer
Intro to Web Dev I Assignment 2: Upload a csv file to populate a textbook catalog, which is filterable by type, year, and rating.   

## Overview
In addition to the assignment requirements, I added a custom CSS for the card hover animation. Otherwise, I used bootstrap for styling.

Created with: HTML, CSS Bootstrap for basic styling and layout, custom CSS for transitions, and Vanila JS.
